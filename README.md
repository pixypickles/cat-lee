# CAT LEE Prototype

スマホ向け横＋縦スクロールのカンフー猫アクション試作です。

## 入っている操作

- 円形スティック
- 攻撃
- 爪
- ダッシュ
- ジャンプ
- 3段コンボ：ジャブ → ストレート → 蹴り上げ
- 上＋攻撃：アッパー
- 後ろ＋攻撃：後退サマーソルト
- 空中攻撃：キック
- ダッシュ＋攻撃：低く踏み込むボディブロー
- ダッシュ＋爪：大振り爪フック＋3本の爪痕
- 壁に接触して爪：壁つかまり
- 壁つかまり後は爪を離しても保持
- 壁つかまり＋ジャンプ：壁ジャンプ
- 壁つかまり中に爪＋上：壁登り
- 壁つかまり中に爪連打：少しずつ壁登り
- 壁つかまり中の攻撃
  - 上＋攻撃：斜め上飛び蹴り
  - ニュートラル＋攻撃：横飛び蹴り
  - 下＋攻撃：斜め下飛び蹴り

## PC操作

- WASD / 矢印：移動
- J：攻撃
- K：爪
- L：ダッシュ
- Space：ジャンプ

## GitHub Pages

1. このフォルダの中身をGitHubの新しいリポジトリへアップロード
2. `Settings`
3. `Pages`
4. `Build and deployment` → `Deploy from a branch`
5. Branch を `main`、folder を `/(root)` に設定
6. 数分後に表示されるGitHub PagesのURLをスマホで開く

## v0.2 調整

- 地上加速を大幅に上げ、入力を離した時の滑りを減らしました
- 通常移動速度をアップ
- ジャンプ、壁ジャンプ、ダッシュの移動量をアップ
- 通常コンボにも踏み込みを追加
- 空中キック、アッパー、サマーソルトの動きを大きく調整
- 壁つかまり時に壁へスナップする方式へ変更
- 壁の判定範囲を広げ、掴み損ねを減らしました
- 壁保持中は壁参照を維持し、床下へズルズル落ちる症状を抑制
- 壁登り速度をアップ
- 壁からの3方向飛び蹴りの飛距離をアップ


## v0.3 調整

- 重力を 2500 → 1850 に弱め、空中滞在時間を長くしました
- ジャンプと壁ジャンプを少し高く調整
- 攻撃時の踏み込み・移動量をさらに強化
- キャット・リーを全身ポーズ方式へ変更
- 攻撃ごとに胴体回転、前傾・反り、頭の遅れ、腰位置、肩、肘、膝、足先を連動
- サマーソルトは全身回転、ストレートは肩と腰を入れる、キックは上体を反対へ逃がす動きを追加
- キャラクター表示を約15%大きくしました

## v0.4 調整
- 横向き固定を基本にし、奥行き方向を疑似回転させる表現を抑制
- 攻撃を「構え→溜め→ヒット→引き戻し→構え」の5段階へ
- キック系は蹴った後に膝を畳み、足を元へ戻すリカバリーを追加
- サマーソルトだけ画面内の全身回転を使用
- 後ろ入力を0.20秒記憶し、後ろ→攻撃でも出やすく調整
- 後ろ＋攻撃を通常空中攻撃より優先し、空中サマーソルトに対応
