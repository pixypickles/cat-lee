# CAT LEE Prototype

スマホ向け横＋縦スクロールのカンフー猫アクション試作です。

## 入っている操作

- 円形スティック
- 攻撃
- 爪
- ダッシュ
- ジャンプ
- 3段コンボ：ジャブ → ストレート → 蹴り上げ
- 上＋攻撃：アッパー
- 後ろ＋攻撃：後退サマーソルト
- 空中攻撃：キック
- ダッシュ＋攻撃：低く踏み込むボディブロー
- ダッシュ＋爪：大振り爪フック＋3本の爪痕
- 壁に接触して爪：壁つかまり
- 壁つかまり後は爪を離しても保持
- 壁つかまり＋ジャンプ：壁ジャンプ
- 壁つかまり中に爪＋上：壁登り
- 壁つかまり中に爪連打：少しずつ壁登り
- 壁つかまり中の攻撃
  - 上＋攻撃：斜め上飛び蹴り
  - ニュートラル＋攻撃：横飛び蹴り
  - 下＋攻撃：斜め下飛び蹴り

## PC操作

- WASD / 矢印：移動
- J：攻撃
- K：爪
- L：ダッシュ
- Space：ジャンプ

## GitHub Pages

1. このフォルダの中身をGitHubの新しいリポジトリへアップロード
2. `Settings`
3. `Pages`
4. `Build and deployment` → `Deploy from a branch`
5. Branch を `main`、folder を `/(root)` に設定
6. 数分後に表示されるGitHub PagesのURLをスマホで開く
